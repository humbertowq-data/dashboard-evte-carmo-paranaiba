# Analisador de Viabilidade Econômico-Financeira (EVTEJA)

Este é um analisador de dados focado em controladoria e engenharia econômica, desenvolvido em Python. A ferramenta foi modelada a partir de premissas reais de infraestrutura urbana inteligente, integrando conceitos de gestão enxuta (Lean) para monitoramento de eficiência.

## 🚀 Funcionalidades

- **Análise Financeira Avançada:** Cálculo automatizado de Valor Presente Líquido (VPL) e Taxa Interna de Retorno (TIR).
- **Métricas Lean de Eficiência:** Indicadores de Margem de Segurança Operacional e Índice de Eficiência de Capital.
- **Simulação de Cenários:** Controles interativos para testes de estresse em CAPEX e OPEX.
- **Exportação Gerencial:** Geração de relatórios executivos oficiais em formato PDF.
